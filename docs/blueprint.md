# **App Name**: Team Rewang

## Core Features:

- User Authentication: User authentication and role management using Firebase Auth with Google Login.
- Dashboard: Dashboard providing a summary of total sales, customer count, weekly target progress, activity line chart, and real-time status breakdown.
- Client Hub: Client hub with pipeline and client tabs, displaying data based on status (prospect, survey, acc, etc.) with drag-and-drop functionality for status changes.
- AI Lead Scoring: AI-powered lead scoring to prioritize prospects based on factors such as engagement, demographics, and purchase history. The tool assists in quickly identifying the most promising leads.
- Tools: Installment Calculator: A suite of calculation tools to compute installments for a potential purchase.
- Profile Management: User profile management to edit personal information and set weekly sales targets. Admin role can modify user roles and status.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to evoke trust and reliability, aligning with CRM's core function.
- Background color: Light gray (#F5F5F5), providing a clean and neutral backdrop to ensure legibility and focus on the data.
- Accent color: A saturated purple (#9C27B0) to add a touch of sophistication and to highlight key interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and readable UI.
- Use a set of simple, consistent icons to visually represent different customer stages and actions.
- Use a clear, tabular layout with intuitive navigation for managing client data efficiently.
- Implement subtle animations for status updates and transitions to provide a seamless user experience.
